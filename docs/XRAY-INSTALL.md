# رفع توقف در Installing xray-core — نسخهٔ ۰٫۶٫۱

## علت پیدا‌شده در کد

نصب‌کنندهٔ پایهٔ پین‌شده، اسکریپت XTLS را با `bash` بدون timeout کلی اجرا می‌کرد و تمام خروجی را به فایل موقت می‌فرستاد. timeout دانلود فایل اسکریپت، دانلودهای داخلی آن را پوشش نمی‌دهد. XTLS تابع curl خودش را تعریف می‌کند؛ retry-max-time به‌تنهایی مانع معطل‌شدن یک اتصال نیست. اگر این فرایند تمام نشود، fallback نوا هرگز فراخوانی نمی‌شود. از قطعهٔ لاگ کاربر نمی‌توان تعیین کرد کدام میزبان یا اتصال روی VPS او معطل شده است؛ برای آن به لاگ واقعی همان VPS نیاز است.

## اصلاح

- فقط پس از بررسی SHA-256 نسخهٔ پین‌شده، patch روی فایل موقت نصب‌کننده اعمال می‌شود؛ ساختار غیرمنتظره رد می‌شود.
- اجرای داخلی XTLS با GNU timeout: ۲۴۰ ثانیه + ۱۰ ثانیه برای خاتمهٔ فرایندهای فرزند. تمام خروجی همزمان به ترمینال و لاگ می‌رود. pipeline با pipefail شکست را حفظ می‌کند.
- دریافت اولیهٔ اسکریپت: دو URL رسمی، هرکدام حداکثر ۶۰ ثانیه. تشخیص tag حداکثر ۳۰ ثانیه.
- پس از شکست/timeout، mirror فعلی نوا با نسخهٔ 26.3.27 و checksum قبلی برای amd64/arm64 استفاده می‌شود؛ اتصال ۲۰ ثانیه، کل انتقال ۳۰۰ ثانیه، توقف کم‌سرعتی ۳۰ ثانیه زیر 1024 بایت/ثانیه. checksum پیش از استخراج/اجرا بررسی می‌شود. اگر هر دو مسیر شبکه بسته باشند نصب صریحاً شکست می‌خورد؛ دورزدن TLS یا checksum وجود ندارد.
- mirror فقط هنگام نبود Xray اجرا می‌شود؛ binary موجودِ سالم downgrade نمی‌شود. فایل mirror باید version را موفق اجرا کند؛ OK کاذب حذف شد.
- agent، UI، پروتکل‌ها، پورت‌ها، گواهی‌ها و دیتابیس نوا تغییر نمی‌کنند. فرایند/سرویس دائمی تازه‌ای اضافه نشده است.

## ادامه روی VPS شما

اگر اجرای قبلی هنوز باز است با Ctrl+C متوقفش کنید و تا پایان فرایند آن صبر کنید؛ دو نصب‌کننده را همزمان اجرا نکنید. VPS یا پوشهٔ نوا را پاک نکنید. پس از آپلود تمام محتویات ZIP در ریشهٔ مخزن alirezaserver، فایل جدید را دریافت کنید:

```bash
curl -fSL --connect-timeout 20 --max-time 120 https://raw.githubusercontent.com/alirezachatgpt97-coder/alirezaserver/main/install.sh -o alirezaserver-install.sh
sudo bash alirezaserver-install.sh --repair
sudo bash alirezaserver-install.sh --check
```

روی نصب کامل موجود ابتدا snapshot/backup نوا و backup افزونه بگیرید. روی نصب ناقص که افزونه هنوز ایجاد نشده است، `--backup` افزونه ممکن است موجود نباشد؛ snapshot VPS مناسب است. اگر package نوا، Xray قابل اجرا و واحد سرویس موجود باشند، نصب پایه تکرار نمی‌شود؛ در حالت ناقص نصب‌کنندهٔ پایه برای ادامه اجرا می‌شود. این مسیر روی VPS واقعی هنوز تست نشده است.

لاگ اصلی در `/var/log/alirezaserver/install-*.log` است. شکست با پیام مرحله و مسیر لاگ پایان می‌یابد؛ نبود هر دو مسیر دانلود خطای واقعی شبکه است و با RAM بیشتر الزاماً حل نمی‌شود. روی child-node خروجی نصب در ترمینال است. توکن enrollment، لینک خصوصی پنل و رمزها را در گزارش عمومی لاگ مخفی کنید.

## آزمون و محدودیت

۱۱ آزمون اختصاصی شامل اجرای واقعی Bash/timeout با اسکریپت موفق، شکست‌خورده، فرزند معطل، fallback موفق/ناموفق، رد checksum، رد binary خراب، هر دو معماری، بررسی محدودبودن patch به بخش Xray و یکسانی payload داخلی است. timeout در آزمون فقط به ۱ ثانیه کوتاه می‌شود. شبکه/curl، آرشیو و systemd mirror شبیه‌سازی شده‌اند؛ دریافت واقعی release و نصب روی VPS یا ترافیک VPN آزمایش نشده‌اند.

برای تکرار آزمون اختصاصی، فایل nova-node.sh از commit ثابت و SHA درج‌شده در SOURCES.md را دریافت کرده و مسیر را در `NOVA_INSTALLER_FIXTURE` به tests/xray-install.py بدهید. این fixture برای اجرای تست است و در ZIP کپی نشده است.
