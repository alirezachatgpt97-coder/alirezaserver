# فرم دستی در ۰٫۷٫۱

پس از انتخاب کارت VLESS/VMess/Trojan/SS2022/forwarding، «ادامه» فرم جدید را باز می‌کند. انتقال و امنیت را خودتان انتخاب کنید و گزینه‌های قابل اعمال را تنظیم کنید. برای TLS فایل‌های /etc/nova/origin.pem و origin.key به‌عنوان مسیر اولیه پیشنهاد می‌شوند؛ وجود/اعتبار آن‌ها و مطابقت دامنه روی همان نود شرط اتصال واقعی است. برای Reality مقصد و SNI را وارد و کلیدها و Short ID را بسازید؛ کلید خصوصی مخفی است و قابل نمایش/پنهان‌کردن است.

در حالت کاربران منتخب، گزینه‌های native کاربران را انتخاب کنید. دادهٔ user/password مستقل ساخته نمی‌شود. سرور raw شامل clients خالی است و نوا طبق مجوزها آن را با credentialهای خودش پر می‌کند. برای SOCKS/HTTP، این جایگزینی مربوط به accounts متفاوت است؛ آن‌ها عمداً در فرم native باقی‌اند. گزینهٔ گرافیکی ناسازگار یا موتور fake اضافه نشده است. اگر اینباند خام را بعداً از دکمهٔ ویرایش اصلی نوا باز کنید، مسیر advanced JSON اصلی همچنان وجود دارد؛ ویرایش گرافیکی round-trip همهٔ raw configهای دلخواه در این نسخه پیاده‌سازی نشده است.

فرم schema جدید فقط برای ساخت common Xray است. IP/پورت/نود/raw از API اصلی ذخیره می‌شوند و اعتبارسنجی/خطا/پورت و lifecycle اصلی حفظ می‌شود. این تغییر فایل agent/protocol نوا را patch نمی‌کند. scriptهای گرافیکی فاقد داده عمومی‌اند؛ API ساخت کلید و تمام مدیریت سرویس فقط برای owner است. پاسخ حاوی کلید فقط به درخواست همان مالک می‌رود و cache ندارد.

این release فرآیند پس‌زمینهٔ جدید، npm build یا حافظهٔ دائمی جدید اضافه نمی‌کند. فرم‌ها فقط هنگام کلیک ایجاد می‌شوند؛ افکت‌ها از modal/input/cardهای نوا استفاده می‌کنند. آزمون مرورگر واقعی همچنان در محیط ممکن نشده است و انطباق تصویری کامل قابل تضمین نیست.

# اینباندهای یکپارچه در ۰٫۷٫۰

## مسیر کار

۱. وارد اینباندها شوید و بالای صفحه «ساخت دستی اینباند» را بزنید.
۲. پروتکل و نوع انتقال/امنیت را انتخاب کنید. فقط گزینه‌های واقعی INB_PRESETS نسخهٔ نصب‌شده نمایش داده می‌شوند.
۳. «ادامه به تنظیمات کامل» فرم اصلی نوا را باز می‌کند: پورت، نود، TLS/Reality، دامنه، مسیر، peerهای WireGuard و JSON پیشرفته طبق قابلیت همان پروتکل. اعتبارسنجی و ذخیره از API اصلی نواست؛ مولد کانفیگ دوم ساخته نشده است.
۴. OpenVPN به کارت مدیریت داخل همین صفحه می‌رود و ساخت سرور را باز می‌کند. CRUD سرور/حساب، رمز مخفی/نمایان، دانلود، لینک اشتراک، گواهی و quota/expiry واقعی از backend قبلی حفظ می‌شوند. حساب‌ها با کاربران نوا ادغام نشده‌اند. URL قدیمی حذف نشده تا bookmarkها نشکنند؛ ورودی مستقل منو حذف شده است.
۵. AmneziaWG/Mieru/MTProto سرویس‌های singleton نوا هستند؛ انتخابشان تنظیمات اصلی همان سرویس را نشان می‌دهد و نمونهٔ تکراری یا آمار ساختگی ایجاد نمی‌کند. AmneziaWG در حالت ساده هم از این مسیر قابل دسترسی است؛ نیاز کرنل/ابزار واقعی تغییر نکرده است.

## مقایسهٔ واقعی

مبنای alirezaserver: main دریافت‌شده در 2026-10-14، installer 0.6.1 (با نسخهٔ محلی به‌جز newline پایانی یکسان). نوا pinned 1.85.4، commit موجود در SOURCES.md. مقایسهٔ alirezapanel از source پین‌شدهٔ قبلی و enum اصلی مدل آن است؛ کد دو پروژه ترکیب نشده است.

| پروتکل | وضعیت در این بسته |
|---|---|
| VLESS / VMess / Trojan | موتور اصلی نوا و فرم native؛ TLS/Reality/FRONT برحسب preset واقعی |
| Shadowsocks | native، SS2022 مطابق preset نوا؛ همهٔ cipherهای پنل دیگر منتقل نشده‌اند |
| WireGuard | native، peer و دانلود اصلی نوا |
| Hysteria2 / TUIC / Naive | موتور sing-box فعلی نوا، فرم native؛ نیاز نسخه/سرویس و TLS واقعی باقی است |
| SOCKS / HTTP / Port forwarding | native؛ تنظیمات اصلی و پیشرفته |
| AmneziaWG / MTProto | سرویس مستقل موجود نوا، دسترسی مستقیم از انتخاب‌گر |
| Mieru | سرویس مستقل موجود نوا؛ امکان جدید این release نیست |
| OpenVPN | backend قبلی حفظ‌شده؛ مدیریت داخل اینباندها؛ فقط سرور اصلی |
| AnyTLS / Hysteria v1 | موتور/مدیریت جدید اضافه نشده است |
| L2TP / PPTP / IKEv2 / OpenConnect / SSTP | موتور، firewall، مدیریت حساب و subscription جدید اضافه نشده‌اند |
| WG-C / GRE / SSH / Mixed / Tunnel | معادل کامل مدیریت پنل دیگر اضافه نشده است؛ forwarding یا outbound موجود را معادل کامل آن‌ها نمی‌نامیم |

این بسته **تمام خواستهٔ انتقال همهٔ پروتکل‌ها را تکمیل نکرده است**. نصب کرنل/daemonهای اضافی، جداسازی حساب/پورت/کلیدها، تولید subscription و rollback هرکدام کار مستقل لازم دارند. صرف افزودن اسم آن‌ها به select پیاده‌سازی محسوب نمی‌شود. پروتکل‌های موجود نوا، Tor و Psiphon و تمام قابلیت‌های قبلی حذف نشده‌اند؛ outboundها در محل اصلی خود باقی‌اند.

## ایمنی و سازگاری

صفحهٔ جدید از کلاس‌ها/متغیرهای اصلی نوا استفاده می‌کند. script کوچک bridge عمومی و فاقد داده است تا قبل از login بارگذاری شود؛ تمام APIهای حساب و OpenVPN همچنان احراز هویت owner و same-origin mutation دارند. داده/گواهی‌ها migrate یا بازنویسی نمی‌شوند. پیام iframe فقط از parent هم‌مبدأ پذیرفته می‌شود و صرفاً فرم ساخت را باز می‌کند؛ خودکار server ایجاد نمی‌کند. در cloud/PaaS فقط presetهای FRONT مجاز نمایش داده می‌شوند و سرویس محلی نمایشی اضافه نمی‌شود.

compat-check قرارداد viewInbounds/openInboundModal/openModal و presetها را برای آپدیت اصلی بررسی می‌کند؛ UI ناشناخته کورکورانه فعال نمی‌شود. عملکرد Nova source اصلی به‌صورت فایل patch نشده؛ یک wrapper کوچک خروجی DOM صفحهٔ اینباندها را تکمیل می‌کند. تست حفظ همهٔ style/script بلوک‌های اصلی PASS است.

## محدودیت آزمون

آزمون DOM شامل فارسی/انگلیسی، جهت، انتخاب security، dispatch به فرم اصلی، دسترسی owner، cloud، singleton و حفظ URLهاست. تست native HTTP/auth روی loopback نسخهٔ واقعی نوا انجام شد. Chromium در محیط با exit139 خاتمه یافت؛ screenshot و آزمون layout واقعی موبایل/دسکتاپ وجود ندارد. ترافیک واقعی VPN، full systemd install/upgrade و سرور محدودشدهٔ یک گیگابایتی نیز تست نشده‌اند.
